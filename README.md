# E-Commerce Inventory & Search System

## Project Description

The E-Commerce Inventory & Search System is a C++ console-based application designed to manage products, inventory, shopping carts, checkout requests, and partner brands.

The system uses different Data Structures and Algorithms (DSA) to organize product information, perform searching and sorting operations, and process customer transactions.

## Project Objectives

* Manage product information and inventory.
* Search products using different searching techniques.
* Organize products using sorting algorithms.
* Manage customer shopping carts.
* Process checkout requests using a queue.
* Store recent product actions using a stack.
* Display and manage partner brands.

## System Features

1. Add and display products.
2. Search products using a Binary Search Tree.
3. Manage inventory using a Singly Linked List.
4. Add and remove products from the shopping cart.
5. Calculate the shopping cart total.
6. Process checkout requests.
7. Display partner brands.
8. Search and sort products.

## Data Structures Used

| Data Structure     | Purpose                      |
| ------------------ | ---------------------------- |
| Singly Linked List | Inventory management         |
| Binary Search Tree | Product searching            |
| Doubly Linked List | Shopping cart management     |
| Queue (FIFO)       | Checkout processing          |
| Stack (LIFO)       | Store recent product actions |
| Linked List        | Partner brand management     |

## Searching and Sorting Algorithms

* Linear Search
* Binary Search
* Insertion Sort
* Quick Sort

## Programming Language

C++

## Development Environment

* Visual Studio Code
* GCC Compiler
* C++17 Standard

## How to Compile

Open the VS Code terminal in the project folder and run:

```bash
g++ -std=c++17 main.cpp Inventory.cpp ProductBST.cpp SearchSort.cpp ShoppingCart.cpp CheckoutQueue.cpp UndoStack.cpp BrandShowcase.cpp -o inventory.exe
```

## How to Run

```powershell
.\inventory.exe
```
